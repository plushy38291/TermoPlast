Mapa de navegación

Zona pública

Entrada

  • Inicio (landing) → Registro / Login
  • Crear cuenta → Login
  • Iniciar sesión → Panel
  • Recuperar contraseña → Login
Zona emprendedor

Hub: Inicio (Panel)

  • Hacer pedido · elegir diseño/material
  • Subir diseño (SVG) → Mis diseños
  • Mis diseños · estado/aprobación
  • Seguimiento · trazabilidad + QR
  • Impacto · métricas y gráficos
  • Puntos de retiro (mapa) · Perfil
Zona administración

Acceso admin

  • Dashboard · KPIs + gráficos (SP)
  • Gestión de pedidos y diseños
  • ABM · materiales, etiquetas, puntos, emprendedores, usuarios
  • Seguridad · auditoría de eventos
  • Exportar CSV/PDF · Crear admin

Flujo típico: Inicio → Registro → Login → Panel → (Subir diseño → aprobación del taller) → Hacer pedido → Seguimiento (QR) → Impacto. El operador/admin entra por admin_login y trabaja el pedido en Gestión, que alimenta el Dashboard.
